Quick start

You need Node.js 18 or later. Nothing else has to be installed by hand.

Windows

  1. Download the ZIP and unzip it.
  2. Double-click start-windows.bat.
  3. If SmartScreen appears, choose More info, then Run anyway.

macOS

  1. Download the ZIP and unzip it.
  2. Control-click start-macos.command, choose Open, then confirm.
  3. If that's blocked, open Terminal in the folder and run bash start-macos.command.

The first run downloads cloudflared from Cloudflare, starts the mock and opens the console at http://localhost:9842. The window then shows the host name to give HAC. Press Ctrl+C in that window to stop.

To run it locally with no tunnel and no download:

node start.js --no-tunnel

Connect Helix Automation Console

  1. Download the Server Automation Connector from your HAC tenant and start it.
  2. In HAC, set the connector's Host Name to the host the start window shows, and Application Port to 443.
  3. Sign in with user BLAdmin, role BLAdmins and password password. These are test values for the mock only.
  4. Open API Inspector in the mock console to watch every call arrive.

The tunnel's address is public while the mock runs, and the mock has default credentials. Use it for test data only, and stop it when you've finished. The tunnel host can change after a restart, in which case update it in HAC.

What you can do

Patch policies

Under Manage > Patch Policies, use Execute Now, wait for the run, then click Sync. HAC shows the scan run, asset status, logs and the dashboard's Patch tab. Create a remediation operation to install patches.

Compliance

Under Manage > Compliance Scan Policies, create a policy from a template such as CIS - Windows Server 2022, then Execute Now and Sync. You get asset rule counts, each asset's rules, logs and the dashboard's Compliance tab.

To fix findings, select the policy on the Compliance tab and click Remediate. After that operation runs, a new scan shows those servers as compliant. Undo compliance remediation under Settings in the mock console resets this for the next demo.

Ad hoc jobs

Under Operations > Create Operation > Adhoc Job Selections, pick from 15 NSH script jobs, 7 deploy jobs and 5 batch jobs. HAC schedules Execute Now about 90 seconds ahead.

The mock console

Browse servers, depot content, catalogs, jobs and live job logs. Under Settings you can change run speed and the failure rate, or reset all data.

Auto-Sync

HAC doesn't show a run's results until someone clicks Sync. The HAC Auto-Sync page in the mock console gives you a script to paste into the browser console of a signed-in HAC tab. It calls Sync every 30 seconds while that tab stays open, and stops after 8 hours. If your HAC session expires, reload HAC and paste it again.

Troubleshooting

"Node.js is required"

Install the LTS version from nodejs.org, then start again.

HAC can't reach the mock

VPNs can block the tunnel. Run node server.js --stop-tunnel, start the mock again, and enter the new host in HAC.

A run finished but HAC shows nothing

Click Sync, or use Auto-Sync. If a compliance Sync fails, HAC keeps that run's partial data, so start a new run.

Start over

Use Settings > Reset all data in the mock console.
